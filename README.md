## The entry

> 🗻

Mount Fuji at dawn: snow on the peak, a red sun rising behind it. One
glance and a stranger sees Japan — not "a holiday", one particular dream:
standing below the mountain, or climbing it, at sunrise. It beats the
obvious picks (beach, plane, palm tree) because it is a place, not a
category — a postcard, not a pictogram of travel in general.

## How it works

`main.ts` writes that single emoji to `/output/entry.txt` and enforces the
sealed gate itself before writing: UTF-8 text, 1 to 8 characters, not only
white space. The character count uses code points, not UTF-16 units, so the
single emoji counts as exactly one character. Run it with Node:

```sh
node main.ts
```
